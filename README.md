## 關於這個網站 / About

這是 **Dato Music Lab** 的作品集網站。它不是一份履歷，而是一個持續長大的實驗室紀錄：把國小音樂教室裡「孩子卡住的地方」，做成可以玩、可以聽、也可以被其他老師改造的聲音經驗。

*This is the portfolio of Dato Music Lab — an evolving record of a small studio where classroom friction becomes playable, listenable, remixable sound experiences.*

> 先聽見孩子，再設計學習。
> *Listen to the child first, design the learning second.*

我不從「還能加什麼科技」開始，而是從孩子怎麼聽、怎麼動、在哪裡失去參與感開始。互動只是後押；真正的主題一直是**學習與表達**。

## 教學理念 / Teaching Method

| | | |
|---|---|---|
| **壱** | 先玩再說 · *Play First* | 奧福取向：從身體打擊、遊戲與律動出發，孩子先「做到」音樂 |
| **弐** | 雙語滲透 · *CLIL* | Ta、Ti-ti 的節奏語言配上英語指令，雙語自然發生 |
| **参** | 科技補位 · *Tech Assist* | 孩子卡住的地方，就是下一個遊戲的規格書 |

> 音樂不是少數人的才藝；它可以是每個人參與世界的一種方式。
> *Music isn't a talent for the few — it's a way for everyone to take part in the world.*

## 給老師 / For Educators

- **PLAY 直接使用** — 多數網頁遊戲不需安裝，打開瀏覽器、接上投影就能開始
- **REMIX 開源改造** — 遊戲、班級工具與 MuseScore 外掛皆公開原始碼，歡迎改成自己的版本
- **TEACH 教學脈絡** — 工具不是課堂的主角，而是讓每個孩子更容易加入

所有遊戲與外掛皆可免費用於課堂與個人用途。
*All games and plugins are free for classroom and personal use.*

## 技術 / Built With

- 純 **HTML + CSS + JavaScript**，無框架、無建構工具 — clone 下來直接開就能看
- 單頁滾動敘事：編輯設計語言、非對稱網格、大型襯線標題與跑馬燈節奏帶
- **Google Fonts** — DM Sans、Noto Sans TC、Noto Serif TC
- **GitHub Pages** 部署，綁定自訂網域（見 `CNAME`）

```
.
├── index.html        # 首頁（單頁作品集）
├── devlog.html       # 開發日誌
├── innovator.html    # Google Innovator 專頁
├── hackfoldr/        # 課程共筆導覽
├── assets/           # 圖片與縮圖
└── CNAME             # 自訂網域
```

本機預覽 / Local preview：

```bash
git clone https://github.com/linyubert/linyubert.github.io.git
cd linyubert.github.io
python3 -m http.server 8000   # 開啟 http://localhost:8000
```
